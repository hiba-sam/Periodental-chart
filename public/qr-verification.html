Générateur de QR Code pour Vérification d'Ordonnance

Paramètres du QR Code

QR Code

Instructions

  1. Sélectionnez un scénario de test dans la liste déroulante
  2. Cliquez sur "Générer QR Code" pour créer un QR code
  3. Scannez le QR code avec votre téléphone pour vérifier qu'il fonctionne
  4. Vous pouvez télécharger le QR code en cliquant sur "Télécharger QR Code"
  5. Pour utiliser une URL personnalisée, entrez-la dans le champ correspondant

Note: Ce générateur crée des QR codes qui pointent vers la page de vérification d'ordonnance.
